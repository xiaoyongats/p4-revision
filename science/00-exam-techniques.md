# Exam Techniques (use for every topic)

## 1. Open-ended questions: the CER method

Most 2-mark "Explain" questions are marked on these parts:

| Part | What to write | Example (wax on rod A melted in 20 s, rod B 45 s, rod C 35 s) |
|---|---|---|
| **C**laim | Answer the question directly | Rod A is the best conductor of heat. |
| **E**vidence | Quote data from the table / graph / diagram | The wax on rod A melted in the **shortest time**, 20 s. |
| **R**easoning | The science concept, using keywords | Heat **flowed through** rod A **fastest**, so the wax **gained heat** and melted first. |

**Rules**
- If the question gives data, **use the data** (quote numbers).
- If the question says "Explain", you must give the **science reason**, not just describe.
- 1 mark ≈ 1 point. A 2-mark question needs **2 points**.

## 2. Use the exact keywords

| ❌ Avoid | ✅ Write |
|---|---|
| gets hot / gets cold | **gains heat / loses heat** |
| steam (meaning the gas) | **water vapour** |
| drinks water (roots) | **absorbs water** |
| food goes into the blood | **digested food is absorbed into the bloodstream** |
| light shines on the eye / eye sends light | **light from the source is reflected off the object and enters the eye** |
| the shadow blocks light | **the object blocks light**; a shadow is formed |
| magnet sticks / pushes | **attracts / repels** |
| air is squeezed | **air can be compressed** |
| takes up the room | **occupies space** |

## 3. Experiment (fair test) questions

These appeared in **every** paper.

| Question | How to answer |
|---|---|
| "What is the aim?" | "To find out if / how **[changed variable]** affects **[measured variable]**." e.g. *To find out how the number of coils of wire affects the number of steel pins attracted by the electromagnet.* |
| "What variable was changed?" | The **one** thing that is different between set-ups. |
| "What must be kept the same?" | Everything else: amount/size/thickness/length of materials, type of light source/torch, distance, starting temperature, time, type of container. |
| "Tick the variables to keep constant" | Do **NOT** tick the changed variable or the measured result. |
| "Which two set-ups should be compared?" | Pick the two set-ups where **only the variable in the aim is different**; everything else is the same. |
| "Why repeat the experiment 3 times?" | To make the results **more reliable**. |
| "Which set-up is the control?" | The set-up used for **comparison** (usually the one with nothing removed). |
| "How to measure more accurately?" | Name the instrument: **light sensor + datalogger**, **temperature sensor + datalogger**, **thermometer**, **electronic balance**, **measuring cylinder**. |

### Method: "Which two set-ups?"
1. Underline the variable in the aim (e.g. *number of batteries*).
2. Find two set-ups where **that** variable is different.
3. Check that **every other variable** (coils, type of nail, wire) is the same.

Example: Aim = number of batteries. A: 2 batteries, 20 coils. B: 3 batteries, 20 coils. C: 2 batteries, 10 coils. → **A and B** (only the number of batteries differs).

## 4. Reading tables and graphs

1. Read the title and both axis labels (what is measured, what units).
2. Describe the **trend** in one sentence: "As **___** increases, **___** increases / decreases."
   e.g. *As the temperature of the surroundings increased, the number of mosquito eggs hatched in a day increased.*
3. For a **bar graph of days in each life-cycle stage**, add up the days in order to find "which stage on day X".
4. For a **temperature–time graph**, a flat part means melting/boiling, or that the substance has reached room temperature.
5. Use **exact numbers** in your answer.

## 5. Flowcharts and classification charts

- Follow each arrow and write the answer to every question on the way. e.g. "Does it have a definite shape? **No**. Can it be compressed? **Yes** → gas".
- **Similarity** between two items: find a question where both went the **same** way.
- **Difference**: find the **first** question where they went **different** ways; state it for **both** items. e.g. *S gives birth to young alive **but** T does not.*
- "**Based only on the information given**": use only what is in the chart, NOT your own knowledge.

## 6. MCQ method

1. Underline **NOT**, **only**, **most**, **best**, **correct**, **always**.
2. For "A, B, C, D statements" questions, mark each statement ✓ or ✗ beside it, then find the option that matches.
3. Cross out options that are clearly wrong.
4. Re-read the question before shading.

## 7. Time and checking (1 h 45 min, 100 marks)

- Booklet A: about 35 min. If you are stuck for more than 2 minutes, circle the question and move on.
- Booklet B: about 55 min.
- Last 15 min: check that every OAS bubble is shaded, units are written (g, cm³, ml, °C), and keywords are spelt correctly (*evaporation, condensation, conductor, translucent, opaque, magnetic*).
