1

How a shadow is formed

Light travels in straight lines. When an object blocks the light, a shadow forms behind it.

Learn this sentence by heart. It is worth 2 marks.

You need

a light source, an object that blocks light, and a screen or surface.

Outline only

A shadow shows only the outline. It has no colour or details.

Holes

A hole lets light through, so there is a bright patch in the shadow.

2

Dark shadow, light shadow, no shadow

OpaqueBlocks all light → dark shadow
metal, cardboard, wood, rubber
TranslucentBlocks some light → light (faint) shadow
tissue paper, frosted glass, tracing paper
TransparentLets most light through → no shadow
clear glass, clear plastic

Predicting a pattern

For each part of the object ask: how much light passes through? All → bright. Some → light shadow. None → dark.

If light passes through several sheets in a row, a bright spot on the screen means light got through every sheet there.

3

Size of a shadow on a screen

Bigger shadow

Object moved closer to the light, or the light moved closer to the object.

Smaller shadow

Object moved closer to the screen (it also gets sharper).

Two objects in a row

The object closer to the torch makes the bigger shadow. A cube in front of a ball of the same size makes a square shadow that hides the ball's.

4

Length of a shadow on the ground

Light is LOW

Morning, evening, or far from a lamp post → long shadow.

Light is OVERHEAD

Noon, or right under a lamp post → shortest shadow.

Walking past a lamp post (A → B under the lamp → C)

The same V-shape happens when a torch moves in an arc over an object from one side to the other.

The shadow is always on the side opposite the light.

Always use the data

In some set-ups (like an object on a table with a low torch) the trend can be different. If the question gives a table, describe what the numbers show.

5

Shape of a shadow

The shape depends on the object's shape and which side faces the light.

Conetriangle (side) or circle (base or tip facing the light). Never a square.
Cylinderrectangle or circle
Cubesquare or rectangle
Ballalways a circle
6

Watch out!

✗The shadow blocks the light.
✓The object blocks the light.
✗Closer to the screen = bigger shadow.
✓Closer to the light = bigger. Closer to the screen = smaller.
✗Explaining a shadow without "straight lines".
✓Always say light travels in straight lines.
✗Ticking "length of shadow" as a variable kept the same.
✓It is the result being measured. Tick neither.

Remember in 3 lines

Light travels in straight lines → object blocks it → shadow
Opaque: dark · Translucent: light · Transparent: none
Near the light → big shadow. Light overhead → short shadow.
