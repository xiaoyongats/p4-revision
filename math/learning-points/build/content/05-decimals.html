3

Comparing and ordering

Line up the decimal points→Fill empty places with 0→Compare from the left

0.607, 0.706, 0.067 → tenths digits 6, 7, 0 → smallest to greatest: 0.067, 0.607, 0.706.

0.5 vs 0.45 → 0.50 vs 0.45 → 0.5 is bigger (more digits does not mean bigger).

4

Rounding

Same rule as whole numbers: look at the digit on the right. 7.46 → 1 decimal place → 7.5. 3.149 → 2 decimal places → 3.15.

Watch out!

✗39 thousandths = 0.39
✓Thousandths = 3 decimal places: 0.039.
✗0.45 > 0.5 because 45 > 5
✓0.5 = 0.50 > 0.45.
✗6.3 − 0.81 = 6.51 (not lining up)
✓6.30 − 0.81 = 5.49.
✗[[7/20]] = 0.7
✓[[7/20]] = [[35/100]] = 0.35.

Remember in 3 lines

Tenths, hundredths, thousandths = 1, 2, 3 decimal places.
Fraction → decimal: make the bottom 10, 100 or 1000.
Add/subtract: line up the points. Multiply: count decimal places. Always estimate.
