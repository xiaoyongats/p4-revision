Line graphs

  • Total: add every point. 60 + 90 + 70 + 110 + 100 = 430.
  • Greatest increase: the steepest line going up. Wednesday → Thursday (+40).
  • Greatest decrease: the steepest line going down. Tuesday → Wednesday (−20).
  • Answer a period as "Wednesday to Thursday", not one day.
4

Pie charts

  • The whole circle = everyone. A straight line through the centre = [[1/2]]. A right-angle corner (□) = [[1/4]].
  • Nuggets = [[1/2]]. Fish balls = [[1/4]] = 41 children, so the whole = 4 × 41 = 164.
  • Cakes + burgers = the other [[1/4]] = 41 → burgers = 41 − 23 = 18.
  • The biggest number in a table gets the biggest slice. 38 out of 100 is a bit more than [[1/3]] of the circle.
