Watch out!

✗Giving the answer for "the end" when the question asks "at first".
✓Underline at first / in the end and check before writing.
✗Alice gives 14 → gap changes by 14.
✓One loses and one gains → gap changes by 2 × 14.
✗Finding 1 unit and stopping.
✓Read the question again: how many units does it ask for?

Remember in 3 lines

Draw it. Equal bars, then mark the extra.
Giving: total stays. Same spending: difference stays.
